What this is (2 minutes, read it once)

This is a hands-on working test — not a quiz. You will build real campaign structures for Meta and Google, do the money maths on our products, and audit a messy account. Everything runs in your browser. Nothing to install.

How to run it
  1. Open the three files you received — meta.html, google.html and this one — by double-clicking them (Chrome or Edge). Keep them in the same folder.
  2. Type your candidate code (given to you by HR) in the box at the top of each file. It changes the numbers so every candidate gets a different set.
  3. Work through the tabs in each file. Your work saves automatically in that browser. When you are done with a file, click Export my work — it downloads a small JSON file.
  4. Send back the three JSON files (details in What to send back).

Station 1 — Meta build meta.html

Build three campaigns in a mock Meta Ads Manager: the ₹24,000 all-access pass, the ₹100 daily pass sold through the app, and walk-in lead generation for one Noida club. Objectives, budgets, audiences, placements, attribution, creative text and UTM tracking — all of it.

~35 minutes

Station 2 — Google build google.html

Build a Search campaign for Noida walk-in leads (brand vs non-brand vs competitor ad groups, keywords and match types, negatives, a responsive search ad within Google's limits, sitelinks, geo targeting, bidding) — then fix five problems in a broken account.

~30 minutes

Station 3 — Money & ROAS this file

The products: ₹24,000 all-access pass, ₹100 daily pass on the app, gym walk-ins, and a ₹45,000 course. You get real-looking last-30-days numbers: work out CPL, CAC, ROAS (including new-customer ROAS), then allocate next month's ₹10,00,000.

~20 minutes

Station 4 — Account audit this file

A 10-row export with things wrong in it. Pick each row's action, and tick what is broken across the account. Numbers must back every call.

~15 minutes

Four rules that decide your result
  1. Numbers or it didn't happen. Every decision needs a number from the data — no opinions.
  2. Say what you would NOT do. If something should not be touched, say it and why. That counts as much as building.
  3. Don't fake it. Your code changes the numbers. Screenshots or copy-paste from someone else will be caught in the call.
  4. Work in your own words. Using AI tools or notes? Fine — but you must be able to explain every number and every setting on a call.

Before you send — 30-second self-check
  • Your candidate code is filled in on all three files and matches the one HR gave you.
  • You filled the plan text in this file — five lines, with numbers.
  • You can explain every number out loud: how you got CPL, CAC and ROAS, and why you moved the budget where you did.
  • You noted at least one thing you deliberately did NOT touch.
After you send
